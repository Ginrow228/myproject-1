Тест 1:
Добавление сети:
Пользователь выбирает в приложении пункт 1 на добавление сети, напоминают, что использовать можно только буквы, числа, пробелы, подчёркивания и дефисы.
Далее просят ввести название которое будет присвоено сети, после корректного ввода просят ввести описание, после ввода пользователя уведомляют,
что сеть была добавлена с критериями которые были указаны.

Тест 2:
Добавление устройства к сети:
Пользователь выбирает в приложении пункт 2 на добавление устройства к сети, далее пользователю показывают к каким сетям можно подключить устройство.
После выбора сети по айди, пользователя просят ввести название устройству, ip-адресс (правильного формата), mac-адресс (правильного формата),
тип-устройства (router, switch, server, other), и статус (active, inactive), после ввода всех критериев, пользователя уведомляют что устройство добавлено к сети.

Тест 3:
Добавление подключения:
Пользователь выбирает в приложении пункт 3 на подключение устройств, после выбора пользователю выводят сети которые зарегистрированы, после выбора сети
пользователя просят выбрать 2 устройства от какого к какому необходимо подключение (при выборе сети у которой меньше 2 устройств пользователя уведомят о том, что невозможно подключить соедиинение
т.к у сети не хватает устройств), пользователь вводит от какого к какому (айди) необходимо подключение, после ввода пользователя попросят ввести тип подключения, и статус.

Тест 4:
Поиск сети по имени:
Пользователь выбирает в приложении пункт 4, после выбора пользователя попросят ввести название сети, после ввода корректной сети пользователю ввыведется информация об этой сети.

Тест 5:
Поиск устройства по имени:
Пользователь выбирает в приложении пункт 5, после выбора пользователя попросят ввести название устройства, после ввода корректного устройства пользователю ввыведется информация об этом утройстве.

Тест 6: 
Вывод всей информации о всех сетях и их устройствах:
Пользователь выбирает в приложении пункт 6, после выбора пользователю выводят всю информацию о всех существующих сетях, количесве подключенных устройств и их информацию.

Тест 7:
Вывод всех устройств и их соединениях к сетям:
Пользователь выбирает в приложении пункт 7, после выбора пользователя попросят ввести айди сети в которой он хочет проверить соединения, далее ему выводят информацию об этих устройствах и их соеднинениях.

Тест 8:
Вывод всей статистики:
Пользователь выбирает в приложении пункт 8, после выбора пользователя попросят ввести айди сети в которой необходимо посмотреть информацию, после ввода айди пользователю выводят более подробную информацию в удобном для чтеиня виде.

Тест 9:
Выход из приложения:
Пользователь выбирает в приложении пункт 9, после чего приложение закрывается без ошибок.

Тест 10:
Тест на валидацию ip-адресса:
При попытке ввести ip неверного формата, пользователя уведомят о том, какой формат предусматривается для добавления устройства.

Тест 11:
Тест на валидацию mac-адресса:
При попытке ввести mac-адресс неверного формата, пользователя уведомя о том, какой формат предусматривается для добавления устройства.

Тест 12:
Тест на валидацию имени:
Когда пользователь пытается ввести в название устройства или сети неверное имя (со различными типов знаков %&@$ и т.д) выводится подсказка в каком формате принимается имя для регистрации сети или устройства.

Тест 13:
Тест на валидацию типа:
Когда пользователь пытается ввести в тип устройства неверные данные (существующие данные это: router, switch, server, other) его уведомляют о том какие типы можно указать.

Тест 14:
Тест на валидацию статуса:
При попытке ввести некорректные данные в поле статуса пользователя уведомляют о существующих статусах для устройства и соединения (active и inactive).

Тест 15:
Если пользователь создал 1 сеть, и добавил туда только 1 устройства, при выборе 3 пункта в приложении пользователя уведомят о том, что не является возможным зарегистрировать соединение.

Тест 16:
После создания пустой сети, если пользователь выберет пункт 8, и введет айди пустой сети - информация которая выведется будет корректной, где будет указано что нет подключенных устройств и зарегистрированных соединений.

Тест 17:
При вводе в поиске по имени сети некорректного имени, выведется сообщение о том что было найдено 0 сетей с подобным названием.

Тест 18:
При вводе в поиске по имени устройства некорректного имени, выведется сообщение о том что было найдено 0 устройств с подобным названием.

Тест 19:
При вводе некорректного номера опции в приложении выведется сообщение о том, что была выбрана неверная опция.
